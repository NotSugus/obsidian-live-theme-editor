# obsidian-live-theme-editor

To use this plugin, do the following:

1. Copy the project files inside of your vault's `.obsidian/plugins` directory
2. In Obsidian, enable the plugin by clicking the switch (refresh if not visible)

## Recomendations

- Use a color palette online software, like [Adobe Color](https://color.adobe.com/es/create/color-wheel)
- To change tags and link colors, add the following under _"Advanced Variables"_:
    - For tags: `--pill-color`, `--tag-color`, `--tag-color-hover`, `--tag-decoration`, `--tag-decoration-hover`
    - For links: `--link-external-color`
